# 🩺 Sistema de Gestão para Consultório Médico

> Sistema web full-stack desenvolvido para otimizar o fluxo de atendimento, controle financeiro e gerenciamento de usuários em clínicas médicas.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de mercado:

### **Frontend**
* **Next.js** (App Router / React)
* **Tailwind CSS** (Estilização moderna e responsiva)
* **Sonner** (Notificações e alertas toast profissionais)
* **TypeScript**

### **Backend**
* **Node.js** com **Express**
* **TypeScript**
* **MySQL** (Banco de dados relacional)
* **JWT** (Autenticação segura)

---

## ✨ Principais Funcionalidades

* 🔐 **Autenticação e Controle de Acessos:** Login seguro com níveis de permissão (Administrador e Usuário comum).
* 👥 **Gestão de Clientes/Pacientes:** Cadastro, edição, listagem e exclusão com validações de segurança.
* 📋 **Controle de Atendimentos:** Registro de consultas, histórico e bloqueio de alterações em atendimentos finalizados.
* 💰 **Gestão Financeira/Despesas:** Relatórios e controle de despesas profissionais por período.
* 🎨 **Interface Moderna:** Design limpo, responsivo e com feedbacks visuais em tempo real via toasts.
